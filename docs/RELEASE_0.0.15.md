# DKC1Recomp v0.0.15 — HD first-level preview

This release adds the current macOS HD texture work as an optional preview.
Choose **Mods > Upscaled HD Textures (Jungle Hijinxs only)** to enable it, or
press F10 for a quick original/HD comparison. The option is off by default and
is remembered between launches.

## Included HD scope

- Jungle Hijinxs scenery and character/object material coverage
- Jungle Hijinxs bonus cave
- Banana Hoard and treehouse fixed-room presentation
- Updated Banana Hoard sign, banana/HUD work, and Diddy animation coverage
- Original textures in every unsupported scene

The label deliberately says “Jungle Hijinxs only”: this is a first-level art
preview, not a whole-game texture pack. The connected rooms above are included
because they belong to the validated first-level slice.

The macOS app also includes the built-in **Dixie Kong Country** switch. It uses
the player's same verified clean DKC1 ROM and keeps Dixie saves separate.

## Packages

- `DKC1Recomp-v0.0.15-macOS-arm64-HD-Preview.zip` — new macOS 26 arm64 HD
  preview, including its SDL2 runtime and HD materials
- `DKC1Recomp-v0.0.13-Windows-x64.zip` — unchanged Windows x64 package copied
  from the prior Windows release for convenience

The release contains no ROM or save state. Supply a clean US DKC1 ROM when the
macOS app asks for it. SHA-256 sidecars are provided for both archives.
